# Desafio Comercial

Programa de terminal em Node.js, sem dependências externas, com as três funcionalidades solicitadas:

- cálculo consolidado das comissões por vendedor;
- entradas e saídas de estoque com identificador único e validações;
- cálculo de juros simples de 2,5% por dia de atraso.

## Execução

Requer Node.js 18 ou superior.

```bash
npm start
```

Para executar as verificações:

```bash
npm test
```

A data de vencimento deve ser informada no padrão `AAAA-MM-DD`.
